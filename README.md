MyLearn is a small online learning platform that was created as part of an MSc coursework project. The goal of the project was to make a role-based web app that lets teachers make structured learning materials and lets students sign up for classes and keep track of their progress.
Flask is used to build the system, which is based on a modular design. Students and teachers can sign up and log in. The interface and actions that are available change depending on the role you choose.
Teachers can make courses, add modules to those courses, and make lessons inside each module. Lessons are the smallest unit of learning in the system and include written teaching material. Students can sign up for courses that are open and follow a set path through modules and lessons. Tracking progress is an important part of the system. You can mark a lesson as finished when a student has finished it. Then, this completion status is used to figure out how far along you are in a module or course. Percentage values and progress bars show progress visually, making it easy for students to see how much of a course they have finished.
The app stores information about users, courses, modules, lessons, enrollments, and completions in a SQLite database. Flask-Login takes care of authentication and session management, and SQLAlchemy is used to connect to the database. The frontend is made with standard HTML templates, Jinja2, and some basic Bootstrap styling. This project is meant to be run on a local machine for testing purposes, not on a public server.
To run the app on your own computer, clone the repository and go to the project folder. Make and turn on a Python virtual environment, install the dependencies you need, and then run the Flask app.
